# Inventory Management System (IMS)

A modern web-based Inventory Management System developed using the MERN stack to simplify and automate inventory operations such as product management, warehouse management, stock tracking, and report generation.

---

## 🚀 Features

- User Authentication using JWT
- Product Management
- Inventory Tracking
- Warehouse Management
- CRUD Operations
- Dashboard Analytics
- Real-Time Inventory Updates
- Report Generation
- Responsive UI
- Secure Data Handling

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Other Tools
- JWT Authentication
- Axios
- REST API
